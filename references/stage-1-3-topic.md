# 阶段 1–3：热点捕捉 · 账号定位 · 价值评估

## §1 阶段 1：热点捕捉与选题池建立

### 输入
- 信源清单（下表）
- 日历事件表：FOMC、CPI/PCE、非农、财报季、大厂发布会、代币解锁日
- 自有账号近 30 条完播率 Top5 的选题标签

### 信源清单

| 领域 | 一手信源（必看） | 二手信源（扫标题） |
|---|---|---|
| Web3 | CryptoQuant / Glassnode 看板、Farside（ETF 流量）、交易所公告、SEC 与监管官网 | CoinDesk、The Block、律动 BlockBeats、吴说区块链 |
| AI 副业 | OpenAI / Anthropic / Google 官方 changelog、工具定价页、App Store 榜单 | Product Hunt、少数派、即刻 AI 圈、X 上 builder 实测帖 |
| 财经 | Fed 官网（声明/点阵图）、BLS（CPI/PCE）、公司 IR 页、交易所公告 | 华尔街见闻、财联社、路透、彭博摘要 |

### 判断标准（能否入池，四条全过）
- [ ] 有一手信源可追溯，不是「某博主说」
- [ ] 至少 1 个可引用的具体数字（金额、百分比、时间点）
- [ ] 能回答「这跟我观众的钱 / 时间 / 认知有什么关系」
- [ ] 不是纯情绪事件（骂战、八卦），除非能落到机制解释

### 池子管理
- 常备量 ≥ 10 条。3 条/周节奏下约够 3 周缓冲。
- 状态流转：`待评估 → 已评分 → 已排期 → 已完稿 → 已发布 → 已复盘`
- 模板：`assets/templates/选题池.md`

### 提示词模板 · 热点扫描

```
你是【Web3 研究员 / AI 副业操盘手 / 财经分析师】（三选一）。
任务：扫描 {日期} 过去 72 小时本领域热点，输出 8–12 个候选选题。

每个选题输出：
1. 一句话选题（≤25 字）
2. 触发事件（发生了什么，含时间与主体）
3. 关键数据点（≥1 个具体数字 + 信源 URL）
4. 时效倒计时（24h / 72h / 长期有效）
5. 与我受众的关联点（他们的钱/时间/认知哪一处被触动）

约束：
- 只收有可追溯信源的事件，社交媒体传言标注「未证实」
- 剔除纯情绪事件、八卦、无数据支撑的观点
- 剔除需要我持有立场站队的政治/地域敏感话题
输出为 Markdown 表格。
```

## §2 阶段 2：受众与账号定位

### 产出物：账号定位卡（一页，三个月不变）

```
账号名：
一句话人设：我帮【谁】解决【什么具体问题】，方式是【什么】
受众画像：性别__ 年龄__ 地域Top3__ 职业特征__
他们的三个真实痛点：1)__ 2)__ 3)__
我的可信度锚点：（真实身份/实测数据/从业年限，必须是真的）
内容边界：说什么 / 绝不说什么（≥5 条）
语言风格：语速__ 称呼__ 禁用词__
更新节奏：每周__ 条，发布时段__
```

### 判断标准
- [ ] 一句话人设能被普通人复述出来（测试：念给家人听，他能说清你干嘛的）
- [ ] 可信度锚点全部真实可查，没有一项是编的
- [ ] 「绝不说什么」清单 ≥5 条，且与平台公约对齐

**首次使用必须填。** 已填过则读 `assets/templates/定位卡.md` 存档，不重复问。

## §3 阶段 3：选题价值评估（五维打分）

### 五维评分表

| 维度 | 权重 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|---|
| 话题度 | 25% | 小圈子自嗨 | 圈内热议 | 破圈，外行也听过 |
| 争议性 | 20% | 结论唯一无讨论 | 有人认同有人反驳 | 两派对立且都有理 |
| 专业门槛 | 15% | 太难（20 秒讲不清） | 需要一层翻译 | 一句话点破的反差 |
| 时效性 | 20% | 长期 evergreen | 1 周内 | 48 小时内 |
| 合规风险 | 20%（**反向计分**） | 高风险 | 需改写规避 | 无风险 |

### 计算公式
```
总分 = 话题度×0.25 + 争议性×0.20 + 专业门槛×0.15 + 时效性×0.20 + (6 − 合规分)×0.20
```

### 决策规则

| 总分 | 决策 |
|---|---|
| ≥ 4.0 | 立即排期，配最好的钩子 |
| 3.0 – 3.9 | 进池观察，等新数据或换角度再评 |
| < 3.0 | 放弃，不占用产能 |
| **合规分 = 1 且无法改写规避** | **一票否决，直接放弃** |

**提级例外**：时效性满分（5）且合规分 ≥4 → 3.0–3.9 分可提级为「立即排期」（窗口期选题过期就没了）。

### 合规风险速判表（1 分钟过一遍）

| 触发情形 | 风险 | 处理 |
|---|---|---|
| 具体币种/股票名称 + 买卖倾向 | 极高 | 改为讲机制不点名，或只做「已发生事实」复盘 |
| 具体目标价位、点位 | 极高 | 删除，改为「历史上这个位置发生过什么」 |
| 收益率、收益截图 | 极高 | 删除，改为讲成本与风险 |
| 推广虚拟币、NFT、合约、挖矿 | **封号级** | 全平台禁发，视频号尤其严格 |
| 引导私信、留联系方式、领资料 | 高 | 删除，改为「评论区聊」 |
| AI 副业类晒收入 / 承诺月入 | 高 | 改为「我跑了 30 天，结果是这样，也可能归零」 |
| 引用未核实数据 | 中 | 回一手信源核对，或删除 |

### 事实核查规则（关键）
> 凡是两个信源给出不同数字、且你无法判断谁对时 —— **不要在视频里说这个数字**。
> 换一个各家一致的数据点，或者干脆不提。宁可信息少一点，也不能被评论区抓到数字打架。

### 提示词模板 · 五维评估

```
你是【短视频主编 + 合规审核员】双重身份。
对以下选题做五维评分（话题度/争议性/专业门槛/时效性/合规风险，各 1–5 分）：

选题：{选题一句话}
原始素材：{数据点与信源}

输出：
1. 五维逐项打分 + 一句理由
2. 加权总分与决策（立即排期 / 进池观察 / 放弃）
3. 合规风险逐条扫描：是否涉及具体标的、点位、收益承诺、引流、涉币推广
4. 若合规分 ≤2，给出 3 条改写建议（保留信息量、去掉风险点）
5. 推荐 2 个不同的切入角度
```

### 提示词模板 · 事实核查

```
你是【合规审核员】。核查以下待用数据点。

数据点清单：
1. {数据} — 信源{URL} — 时间{日期}
2. ...

逐条输出：
- 核查结论：通过 / 存疑 / 证伪
- 四要素是否齐全：数字、口径、时间、来源
- 是否有第二个独立信源交叉验证
- 若发现与其他信源冲突，明确指出冲突点，并给出建议：换数据点 / 标注口径 / 删除

最后输出一份「可安全引用清单」，只保留全部通过的数据点。
```
