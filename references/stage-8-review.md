# 阶段 8：发布后数据复盘与迭代

---

## 核心指标与基准线

| 指标 | 健康线 | 诊断含义 | 低了怎么改 |
|---|---|---|---|
| 3 秒完播率 | > 65% | 钩子 + 前 3 秒画面 | 换钩子类、结论前置、删掉自我介绍 |
| 完播率 | > 35% | 中段节奏与信息密度 | 砍掉第 3 个证据点、中段加一次转折 |
| 点赞率 | > 3% | 价值认同度 | 强化结论的「可带走感」 |
| 评论率 | > 0.5% | 话题争议性 + 互动引导 | 结尾改二选一提问、评论区自己先答一条 |
| 转发率 | > 0.8% | 社交货币属性 | 加一句「可以转给还在 X 的朋友」 |
| 涨粉率 | > 0.5% | 人设一致性 | 检查选题是否偏离定位卡 |

## 复盘表（每条一条，3 分钟填完）

模板见 `assets/templates/复盘表.md`。

```
| 编号 | 领域 | 标题 | 钩子类 | 3秒完播 | 完播率 | 点赞率 | 评论率 | 涨粉 | 平台提示 | 归因一句话 | 下条改什么 |
```

---

## 迭代规则（触发即执行）

| 触发条件 | 动作 |
|---|---|
| 连续 3 条同领域 3 秒完播率 < 55% | 该领域钩子库全部重做 |
| 单条完播率高于均值 30% | 拆它的结构，沉淀成模板进库 |
| 收到平台限流/违规提示 | 立即进合规复核，同模板稿件全部复查 |
| 每月一次 | 选题标签聚类：Top3 标签下月产能占比提到 60% |

## 失败模式对照表

| 症状 | 根因 | 解法 |
|---|---|---|
| 3 秒完播低 | 钩子是标题党、或开头有自我介绍 | 删掉前 3 秒一切铺垫，结论直接甩出来 |
| 完播率低 | 中段信息过载 / 证据点超 3 个 | 只保留 2 个证据点，中段加一次「但是」 |
| 评论少 | 结尾是「点赞关注」 | 改成二选一提问，并在评论区自己先答一条 |
| 被限流 | 踩合规红线 / 同质化模板 | 跑合规清单；同一模板连续使用不超过 3 条 |
| 涨粉慢 | 选题漂移，粉丝画像被稀释 | 回到定位卡，砍掉偏离标签的选题 |
| 念稿卡壳 | 书面语长句 / 数字太大没换算 | 拆句；数字换算后再念一遍 |

## 提示词模板 · 复盘

```
你是【增长负责人 + 短视频主编】。基于以下数据做单条复盘与迭代建议。

数据：{贴复盘表该行}
同账号近 20 条均值：3秒完播__% 完播__% 点赞__% 评论__%

输出：
1. 与均值对比，标出最强项和最弱项
2. 最弱项的根因判断（钩子/结构/选题/发布时段/画面），给出 2 个可能原因
3. 下一条的 3 条具体改动指令（可执行，不要「优化内容」这种废话）
4. 是否把这条的结构沉淀为模板（是/否 + 理由）
```

---

## 模板沉淀格式

单条表现好时，按这个格式进库：

```
模板名：【XXX】型结构
钩子：{钩子公式}
冲突：{怎么摆矛盾}
论证：{证据点数量与排列方式}
结论：{给框架还是给动作}
互动：{提问方式}
适用：{什么场景能套}
不适用：{什么场景套了会翻车}
出处：{原始视频编号}
```
