# 口播稿模板（60–90 秒 / 300–540 字）

## 标注符号

| 符号 | 含义 | 用法 |
|---|---|---|
| `｜` | 短停顿 0.3s | 主谓之间、列举之间换气 |
| `‖` | 句中停顿 0.5s | 信息点之间，给观众消化 |
| `⏸` | 长停顿 1s | 转折前、抛问题后、揭晓答案前 |
| `【重音】` | 加重 | 关键词，每 20 秒最多 1 处 |
| `【升调】` | 句尾上扬 | 设问、悬念 |
| `【降调】` | 句尾下沉 | 下判断、收尾 |
| `【快】` | 提速 | 铺陈、举例 |
| `【慢】` | 放慢 | 关键结论、数字 |

---

## 稿子正文

```
【① 钩子｜0–3 秒｜语速正常，不带情绪】
{≤15 字，单点冲击，不铺垫不自我介绍}

【② 冲突｜3–15 秒｜关键句【慢】，制造反差】
{摆事实 + 点出大众的直觉误解}
{数据点 1}

【③ 论证｜15–50 秒｜证据 1【快】，机制解释【慢】】
{证据点 2：第二个数字，解释前面的现象}
{证据点 3：机制解释 + 生活类比}

【④ 结论｜50–75 秒｜【降调】，一句一顿】
{给可复用的判断框架，不下操作结论}

【⑤ 互动｜75–90 秒｜【升调】，语气放松】
{开放式提问或二选一}

【免责声明｜8–10 秒｜【慢】，语气平，不要含糊带过】
{按领域选 compliance.md 对应模板}
```
