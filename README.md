# koubo-pipeline · 口播视频生产流水线

把「想到什么发什么」变成「选题池里排队、评分后筛、模板化出稿、数据驱动迭代」的 8 阶段工作流。

覆盖 **Web3 / AI 副业 / 财经金融** 三个领域，产出 60–90 秒竖屏口播的完整内容包。

---

## 它解决什么

做口播最耗时的不是写稿，是前面那些不确定的事：今天发什么、这个选题值不值得做、开头怎么说、合规会不会踩线。

这套流水线把每个环节都变成**有输入、有产出、有判断标准、有提示词模板**的固定动作：

| 阶段 | 名称 | 产出物 |
|---|---|---|
| 1 | 热点捕捉与选题池 | 选题池表格（≥10 条） |
| 2 | 受众与账号定位 | 账号定位卡 |
| 3 | 选题价值评估 | 五维评分表 + 决策 |
| 4 | 切入角度与开头钩子 | 6 个钩子候选 + 选定 1 |
| 5 | 内容结构框架 | 五段拆分表 |
| 6 | 口播稿撰写 | 带停顿语气标注的口播稿 |
| 7 | 标题与封面文案 | 5 标题 + 3 封面 |
| 8 | 发布后复盘与迭代 | 归因 + 下条改动 |

---

## 五个专家角色

不是让一个 AI 干所有事，而是给每个环节定义清楚谁负责：

| 角色 | 介入阶段 | 职责 | 否决权 |
|---|---|---|---|
| Web3 研究员 | 1、3、5 | 链上数据、资金流、协议机制、监管动向 | 无 |
| AI 副业操盘手 | 1、3、5 | 工具实测、流程拆解、成本核算 | 无 |
| 财经分析师 | 1、3、5 | 宏观与财报解读、指标口径校准 | 无 |
| 短视频编剧 | 4、5、6、7 | 钩子、结构、口语化、节奏、互动 | 无 |
| **合规审核员** | **3、4、6、7 全程** | 平台公约比对、事实核查、免责声明 | **一票否决** |

---

## 三领域差异（同一个流程，不同的判断标准）

| | Web3 | AI 副业 | 财经金融 |
|---|---|---|---|
| 受众心理 | 怕错过、怕被割 | 怕落伍、想多赚一份 | 怕亏钱、想听懂宏观 |
| 时效性 | 24–72 小时过期 | 1–4 周有效 | 跟日历事件 |
| 合规风险 | 最高（涉币禁发） | 中（禁收益承诺） | 高（禁荐股禁点位） |

完整对照见 `references/domain-diffs.md`。

## 两个脚本

### score.py — 选题该不该做，算一下

```bash
python3 scripts/score.py -t 4 -c 4 -b 4 -ti 5 -co 4 -n "ETF资金流为什么骗了你"
```

输出加权总分与决策。内置两条规则：
- 总分 ≥4.0 立即排期；3.0–3.9 进池观察；<3.0 放弃
- **合规分=1 → 一票否决**，不管总分多高
- **提级例外**：时效性满分且合规 ≥4，窗口期选题可提级排期

### wordcount.py — 稿子写完必跑

```bash
python3 scripts/wordcount.py draft.md
```

剥离停顿与语气标注后统计净字数，按 5.5 字/秒估时长，检查四件事：
- 时长是否落在 60–90 秒（270–540 字）
- 单个气口是否 >20 字
- 停顿与语气标注是否齐全
- 是否命中合规高危词、是否带免责声明

## 字数–时长校准（很多人在这里搞错）

中文口播实际速率 **4.5–6 字/秒**：

| 时长 | 字数 |
|---|---|
| 60 秒 | 270–360 字 |
| 90 秒 | 400–540 字 |
| 600 字 | 约 100–130 秒 |
| 900 字 | 约 150–200 秒 |

**600–900 字是 2–3 分钟中视频的量**，塞不进 60–90 秒。

## 合规

`references/compliance.md` 收录了各平台金融内容规则，含视频号《金融行业公约》（2026-04-01 生效）的 8 类禁止内容，以及财经 / Web3 / AI 副业三类的免责声明模板（口播版 + 字幕版）。

**这不是法律意见。** 平台规则频繁更新，发布前请以各平台最新公约为准。
