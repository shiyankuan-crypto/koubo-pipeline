# 合规红线与免责声明模板

合规审核员全程使用。触发任意红线且无法改写规避 → 一票否决。

---

## 1. 三领域共同绝对红线（跨平台通用）

- 不承诺收益
- 不给具体买卖点位
- 不引导私信 / 加微信
- 不晒收益截图诱导
- 不虚构「内部消息」
- **不推广虚拟币与 NFT**
- 不做同质化模板内容

---

## 2. 平台差异

| 平台 | 严格程度 | 特别注意 |
|---|---|---|
| **视频号** | **最严** | 《金融行业公约》2026-04-01 生效。8 类黑名单含「推广数字虚拟币、NFT」。处罚：限流、删视频、**取消账号认证、封号** |
| 抖音 | 高 | 《抖音社区财经行业公约（试行）》，金融机构及从业人员须完成平台认证 |
| 小红书 | 中高 | 涉投资理财内容审核趋严，软广识别强 |
| B 站 | 中 | 财经区需 UP 主自律，涉币内容限制较多 |

### 视频号金融行业公约 8 类禁止内容（2026-04-01 生效）
1. 违法推荐：明示或暗示具体投资品种的买卖时机、价格建议、预测走势
2. 承诺收益：保本保息、稳赚不赔、X 天翻倍
3. 恶意唱衰：捏造虚假信息、歪曲解读国家宏观经济政策
4. 违规服务：推广洗钱、非法集资、非法套现、非法货币兑换、非法避税
5. 伪造背书：虚构「内部消息」「独家爆料」、冒用监管部门名义
6. 同质化低质内容：脚本雷同、模板化、表现形式高度一致
7. **高风险投资项目：推广数字虚拟币、数字藏品（NFT）**
8. 视频引流：展示联系方式、以领取资料为诱饵，诱导脱离平台交易

> 对加密内容创作者的含义：视频号上**讲机制、讲数据可以，但任何形式的推广都不行**。认证过「财经博主」的账号风险更高（会被撤销认证）。

## 3. 终稿合规筛查清单（10 项，逐条打勾）

- [ ] 无具体标的推荐（币名 / 股票代码 + 正向描述）
- [ ] 无目标价位、点位、时间窗口的具体预测
- [ ] 无收益率、收益截图、收入承诺
- [ ] 无「保本」「稳赚」「翻倍」类表述
- [ ] 无引导私信、加微信、领资料、外部链接
- [ ] 无虚拟币 / NFT / 合约 / 挖矿推广
- [ ] 无「内部消息」「独家爆料」等无法证实的表述
- [ ] 所有数据均有信源与时间戳
- [ ] 已插入对应领域的免责声明（口播 + 字幕双份）
- [ ] 结论是「判断框架」而非「操作指令」

## 4. 免责声明模板

### A. 财经金融类 · 口播版（8 秒）
> 以上是公开数据和我的个人理解，**不构成投资建议**。市场有风险，做任何决定前请自己核实，也别把别人的判断当成你的操作依据。

### A2. 财经金融类 · 字幕 / 简介版
> 数据来源：{机构名}（{日期}）。本内容仅作信息分享与逻辑讨论，**不构成任何投资建议**，不推荐任何具体标的。市场有风险，投资需谨慎，决策请独立判断并自负盈亏。

### B. Web3 / 加密类 · 口播版（10 秒）
> 再说一遍：这里只讲机制和公开数据，**不构成投资建议**，我也不推荐任何币种。这个市场波动极大，杠杆和高收益承诺基本等于风险本身，看不懂的东西不要碰。

### B2. Web3 / 加密类 · 字幕 / 简介版
> 数据来源：{链上/机构名}（{日期}）。本内容仅为区块链与加密市场知识科普，**不构成投资建议**，不推荐、不代购、不引导任何代币或平台。数字资产波动剧烈，存在本金全损风险，请遵守所在地法律法规参与。

### C. AI 副业类 · 字幕 / 简介版
> 本内容为个人实操记录，结果为特定条件下的个案，**不代表普遍收益**，不构成任何收入承诺。工具规则与平台政策随时可变，请以官方说明为准。

---

## 5. 免责声明使用规则

- 口播版必须**本人说出**，不能只放字幕（平台会识别音频）
- 位置：视频结尾互动前（推荐，不伤完播）；或片头 2 秒内快速带过
- 财经与 Web3 类必带；AI 副业类涉及收入数字时必带
- 视频号、抖音、小红书**三平台都要带**，不可只在简介里写

---

## 6. 改写技巧：保留信息量、去掉风险点

| 原表述（危险） | 改写后（安全） |
|---|---|
| 「比特币 8 万是强支撑，可以抄底」 | 「有机构把 8 万算作企业持仓的账面成本区」（已发生的事实陈述） |
| 「这个币下个月能翻倍」 | 「历史上同类事件的波动区间是这样的」（讲历史不讲未来） |
| 「跟着我做，月入三万」 | 「我跑了 30 天，结果是这样，也可能归零」 |
| 「加我微信领资料」 | 「评论区说说你的看法」 |
| 「内部消息，下周有大利好」 | 删除无法证实的表述 |

**判断标准**：改写后保留原信息量 ≥80%，且不产生任何「可以据此操作」的暗示。
